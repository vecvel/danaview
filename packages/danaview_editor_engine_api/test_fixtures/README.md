# danaview_editor_engine_api test fixtures

Shared by the Dart tests of this package, the Swift (`example/ios/RunnerTests`) and Kotlin
(`android/src/test`, `android/src/androidTest`) suites of `danaview_editor_engine`, and the QA suites.
Every file is plain JSON, PNG or a documented binary format so Swift and Kotlin load them without
Dart.

| Directory | Owner | Content | Format |
|---|---|---|---|
| `vectors/` | API-03 | render-math, keyframe, transform, gain, audio-mix, typewriter and 8× text vectors | [vectors/README.md](vectors/README.md) |
| `images/` | API-03 | reference-renderer goldens with their plans and source content | [images/README.md](images/README.md) |
| `sprites/` | API-04 | `.vsprite` fixtures | documented by API-04 |

`vectors/` and `images/` are generated by `dart run tool/regen_goldens.dart` (API-03); run it with
`--check` to verify a clean tree produces no diff.

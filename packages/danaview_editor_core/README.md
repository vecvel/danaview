# danaview_editor_core

Pure-Dart editing core of the Danaview video editor (ARCH §4.3): time model and frame grid, immutable
domain model, editing commands and snapshot history, SRT/VTT and LUT formats, project
persistence, media pool, and the RenderPlan v1 contract shared with the native engines.

- No `package:flutter`, no `danaview_*` dependency; `dart:io`/`dart:isolate` only under
  `lib/src/store/` (enforced by `test/purity_test.dart`).
- Public barrels: `model.dart`, `ops.dart`, `eval.dart`, `formats.dart`, `plan.dart`,
  `codec.dart`, `store.dart` (fixed after CORE-01).
- Normative RenderPlan sources: `schema/render_plan.v1.schema.json`,
  `schema/effects_reference.md`; contract fixtures in `test/fixtures/render_plans/contract/`.
- Shared frame-grid vectors (read by the Dart, Swift and Kotlin tests):
  `test/fixtures/vectors/frame_grid.json`, regenerated by `dart run tool/gen_frame_vectors.dart`.

Run: `dart pub get && dart analyze --fatal-infos && dart test` (or `scripts/ci/editor/core.sh`).
